## AntivirusMVP v0.1.0 Beta

> ⚠️ **Beta 測試版**：個人學習專案，不能取代 Windows Defender。請保持原有防毒軟體開啟。

### 下載與安裝
1. 下載下方的 `AntivirusMVP-Setup-0.1.0-beta.exe`
2. 執行後若出現「Windows 已保護您的電腦」，點「其他資訊 → 仍要執行」（安裝程式尚未數位簽章）
3. 閱讀並同意使用條款後完成安裝，不需要系統管理員權限
4. 第一次開啟會自動下載 ClamAV 病毒碼（數百 MB，需要幾分鐘）

### 驗證檔案（SHA-256）
在 PowerShell 執行 `Get-FileHash .\AntivirusMVP-Setup-0.1.0-beta.exe`，結果應與下列相同（大小寫不拘）：

```
{{SHA256}}
```

### 功能
- 手動掃描檔案或資料夾（雜湊比對 + ClamAV 1.5.4）
- 隔離區：還原或永久刪除
- 自動監控資料夾（預設「下載」），發現威脅自動隔離
- 網址檢查（本機規則，可選用 Google Safe Browsing）
- 掃描紀錄

### 限制
- 沒有即時防護，無法阻擋正在執行的惡意程式
- 沒有行為偵測、勒索軟體防護、防火牆
- 可能漏掉威脅，也可能誤判正常檔案
